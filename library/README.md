# Материалы UMap

Скопируйте сюда свои файлы, чтобы добавлять их на стол без повторной загрузки через браузер.

- `maps/` — карты: PNG, JPEG, WebP или GIF.
- `tokens/` — изображения токенов.
- `objects/` — изображения неживых объектов.
- `music/` — музыка: MP3, OGG, WAV, M4A, WebM или AAC.
- `sounds/` — короткие звуковые эффекты.

Файлы появятся в соответствующей вкладке UMap автоматически в течение нескольких секунд. Эта папка не очищается при сбросе стола или закрытии игровой сессии.
