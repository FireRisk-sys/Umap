# UMap

Локальный виртуальный стол для D&D и других настольных игр. Хост запускает приложение на своём компьютере, а остальные игроки подключаются через браузер по локальной сети.

## Запуск

Требуется **Node.js 20 или новее**.

```bash
npm install
npm run dev
```

В терминале появятся адреса:

- **Host** — `http://localhost:8000/?host=1`. Откройте на компьютере ведущего.
- **LAN** — например, `http://192.168.1.10:8000/`. Отправьте игрокам в той же локальной сети.

Если LAN-страница не открывается, разрешите Node.js частные сети в брандмауэре Windows. Не пробрасывайте порт в интернет: приложение рассчитано на доверенную локальную сеть.

Production-режим:

```bash
npm run build
npm start
```

По умолчанию используется порт `8000`; его можно изменить через переменную окружения `PORT`.

## Игроки и права

Игрок вводит имя и отправляет заявку. Хост принимает её во вкладке **«Игроки»**. Одобренный игрок и назначенные ему токены сохраняются при временном обрыве сети. После восстановления соединения или перезагрузки страницы вход выполняется автоматически по сохранённому ID, без новой заявки.

Хост управляет картами, объектами, всеми токенами, сеткой, очередью и звуковыми эффектами. Игрок может загружать и добавлять свои токены через ПКМ, а двигать только назначенные ему. GM может передать владельца токена в его настройках. Музыкальный плеер общий.

## Карта, токены и объекты

Во вкладке **«Стол»** хост загружает карты или добавляет их из локальной библиотеки. Токены и объекты кладутся на стол нажатием на изображение.

При загрузке токена можно оставить исходную картинку или обрезать её в круг, изменив масштаб и положение кадра. Выбранный объект можно переименовать, повернуть, изменить в размере или удалить. Для токена также назначается владелец.

Управление:

- колесо мыши — масштаб;
- перетаскивание фона — перемещение стола;
- перетаскивание токена — движение с отображением целевой клетки уже во время жеста;
- угловые маркеры выбранного токена/объекта — изменение размера.

В квадратной сетке размер округляется до `1×1`, `2×2` и так далее. Нечётные токены встают в центр клетки, чётные — на пересечение. В hex-сетке используется ширина ячейки и вершины для чётных размеров. Вне сетки и для объектов размер свободный.

## Несколько карт и контекстное меню

На один стол можно добавить любое количество изображений. В разделе **«Карты на столе»** выбирается активное размещение, меняются X, Y и масштаб. Карту можно перетаскивать через пункт **«Переместить карту»** контекстного меню. Удаление размещения не удаляет файл из библиотеки.

**Правая кнопка мыши** открывает действия в точке клика:

- на пустом месте и на карте — добавить токен, объект или карту;
- на карте — настроить сетку или зрение, переместить или убрать размещение;
- на токене/объекте — настройки, очередь и удаление.

Добавляемый токен сразу привязывается к сетке с учётом масштаба карты.

## Отдельные столы

Селектор в верхней панели переключает независимые столы. Кнопка **«+»** создаёт новый. У каждого стола свои размещения карт, токены, очередь и поле зрения; при переключении они сохраняются. Библиотека файлов и музыка общие.

## Сетка и особые зоны

Для карты настраиваются тип и размер сетки, смещение, цвет и прозрачность. Кнопка **«Область»** задаёт прямоугольную область действия базовой сетки.

Кнопка **«Вырез»** создаёт особую зону двумя способами:

- одиночные клики по углам — произвольный полигон, завершение через **Enter**;
- нажатие с протягиванием — прямоугольная зона.

**Esc** отменяет текущее рисование. Для зоны можно выбрать квадратную, шестиугольную сетку или вариант **«Без сетки»**. Верхняя зона в списке перекрывает нижние.

У hex-зоны по умолчанию включён **autoSize**: ширина hex-ячейки совпадает с шириной квадрата базовой сетки и автоматически меняется вместе с ней. Автоподгонку можно выключить и задать размер вручную.

Отдельные кнопки удаляют базовую сетку, одну зону или все зоны. Для ускорения больших карт линии строятся только в видимой части стола и кэшируются; при слишком мелкой сетке появляется рекомендация увеличить масштаб.

## Поле зрения и преграды

Вкладка **«Зрение»** в настройках активной карты включает туман для игроков. Хост видит всё, а кнопка **«Туман»** включает у него предпросмотр скрытых областей.

- Собственный токен игрока выпускает лучи во все стороны. Чужие токены свет не создают.
- Настраиваются радиус, количество лучей и сила затемнения.
- Прямоугольные и полигональные преграды останавливают лучи. За ними карта и сущности скрыты от игроков.
- Если у игрока нет токенов на карте, она полностью затемнена.

В режиме **«Зрение»** протягивание создаёт прямоугольную преграду, клики — полигон. **Enter** завершает, **Esc** отменяет. После создания преграды режим сохраняется, поэтому можно рисовать следующую сразу. Контуры преград видны только хосту; они не ограничивают передвижение токенов.

## Пустые карты и кисти

**«Создать карту»** во вкладке «Стол» создаёт однотонную поверхность с выбранными именем, размерами и цветом. Её можно редактировать как загруженную карту.

Кнопка **«Кисть»** включает цветные линии поверх карты. Цвет и толщина настраиваются в тулбаре. Линии GM сохраняются до удаления, тактические линии игрока исчезают через 15 секунд. «Отменить» удаляет последнюю линию, «Очистить» — доступные автору рисунки. Кисть остаётся включённой для следующих штрихов.

## История и удаление действий

Во вкладке **«История»** хост может отменить или повторить до 50 изменений: сетку и зоны, карты, перемещение и размер токенов, очередь, удаления и очистку стола.

- **Ctrl+Z** — отменить действие.
- **Ctrl+Y** или **Ctrl+Shift+Z** — повторить отменённое.

Подключения игроков, play/pause, громкость и одноразовые звуки не записываются. История очищается при закрытии сессии.

## Очистка и закрытие сессии

**«Очистить стол»** убирает карты, токены, объекты, сетки и медиа, но оставляет игроков подключёнными. Очистку можно отменить через историю.

Красная кнопка **«Закрыть»** в правом углу хоста завершает сессию для всех:

- игроки отключаются и не переподключаются автоматически;
- состояние, история и временные загрузки удаляются;
- локальная папка `library/` сохраняется;
- хост может сразу начать новую сессию без перезапуска сервера.

## Локальная библиотека материалов

Можно копировать файлы прямо на компьютер хоста:

```text
library/
  maps/     — карты
  tokens/   — токены
  objects/  — объекты
  music/    — музыка
  sounds/   — звуковые эффекты
```

Файлы появятся в соответствующих вкладках автоматически в течение нескольких секунд. Кнопка **«Добавить»** помещает их в текущую игру без повторной загрузки через браузер. Поддерживаются PNG, JPEG, WebP, GIF, MP3, OGG, WAV, M4A, WebM и AAC. Эта папка не очищается при сбросе или закрытии сессии.

## Очередь хода, музыка и звуки

Во вкладке **«Ход»** хост добавляет токены в очередь, меняет порядок и вручную переключает ход. Текущий участник выделяется в списке и подсвечивается на карте. Очередь можно очистить целиком.

Во вкладке **«Музыка»** доступны локальные аудио и YouTube-ссылки, play/pause, остановка, предыдущий/следующий трек, повтор и громкость. У хоста есть вкладка **«Звуки»** для одноразовых эффектов без изменения музыкальной очереди.

Каждый участник должен нажать **«Включить звук»**: браузеры запрещают autoplay без действия пользователя. Выключение звука работает только локально и не останавливает музыку остальным; при повторном включении трек продолжается с той же позиции. Для YouTube нужен интернет; используется официальный IFrame Player API, видео не скачивается.

## Данные и проверка

- `data/session.json` — текущая сессия;
- `data/uploads/` — временные загрузки;
- `data/host.json` — локальный ключ хоста;
- `library/` — постоянные материалы пользователя.

```bash
npm test
npm run build
```
